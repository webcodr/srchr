# Bundled assets

## `tokyonight_night.tmTheme`

Sublime Text / TextMate color scheme for the "Night" variant of the
[Tokyo Night](https://github.com/folke/tokyonight.nvim) theme, used by
`preview.rs` to drive syntect syntax highlighting.
